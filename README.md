# 🍃 Proyecto Spring Boot Framework

Repositorio dedicado al aprendizaje, práctica e implementación de funcionalidades del framework **Spring Boot 4.1.1**. Incluye la creación de API RESTful, persistencia de datos y aplicación de buenas prácticas de desarrollo backend.

---

## 🛠️ Tecnologías Utilizadas

* **Java 26**
* **Spring Boot 4.1.1**
* **Spring Data JPA** (Persistencia y modelado de datos)
* **Maven** (Gestión de dependencias y construcción)
* **H2 / PostgreSQL** (Base de datos)

---

## 🎯 Contenidos y Módulos

* **Fundamentos de Spring:** Configuración de Beans, Inyección de Dependencias y Anotaciones Principales.
* **Desarrollo de API REST:** Manejo de Controladores (`@RestController`), Rutas (`@RequestMapping`) y Respuestas HTTP.
* **Persistencia:** Mapeo Objeto-Relacional (ORM) con Entidades JPA y Repositorios.
* **Gestión de Errores:** Manejo global de excepciones.
